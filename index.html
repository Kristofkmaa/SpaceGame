NEBULA COMMAND

Stratégie en temps réel dans l'espace

Extrayez des minéraux des astéroïdes, construisez une flotte et détruisez la station ennemie.

Contrôles

  • Clic gauche / glisser : sélectionner (Maj pour ajouter)
  • Clic droit : déplacer / attaquer / extraire selon la cible
  • A puis clic : attaque en mouvement  •  S : stop
  • Ctrl + 1‑5 : créer un groupe  •  1‑5 : rappeler le groupe
  • Flèches / bord d'écran / clic milieu : caméra  •  Molette : zoom
  • Espace : centrer sur la station  •  P : pause  •  Échap : annuler

Victoire

Aide

  • Collecteur : clic droit sur un astéroïde pour extraire. Il revient déposer à la station automatiquement.
  • Station : produit toutes les unités. Sélectionnez‑la pour lancer la production. Clic droit avec la station sélectionnée définit le point de ralliement.
  • Chantier : produit les vaisseaux de combat plus près du front.
  • Tourelle : défense statique à longue portée.
  • Chasseur : rapide et fragile. Frégate : polyvalente. Croiseur : lent mais dévastateur.
  • Les bâtiments se placent à proximité d'un bâtiment existant.
